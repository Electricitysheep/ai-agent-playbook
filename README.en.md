## ✨ What is this

Not another link collection — a **deep engineering notebook for the AI Agent era**:

- 🧠 **Source-level agent architecture analysis**: Claude Code Agent Teams, Devin message architecture, omp hub IPC concurrency — reading source, not just docs
- 🤝 **Agent-to-Agent protocol research**: A2A protocol ecosystem, 14-agent comparison matrix, MCP-bridge landscape
- 📈 **AI × Quant Finance full pipeline**: from LLM factor mining, TSFM time-series model selection, RL optimal execution, to 16 runnable code experiments
- 📰 **Deep industry insights**: Harness open-source landscape, model release analysis, frontier paradigm tracking

Every report is annotated with **evidence sources and confidence tiers** (official docs / community reverse-engineering / local empirical testing). No secondhand retelling.

## 🎯 Who is this for

- **AI engineers / Agent developers**: understand mainstream agent architectures and messaging mechanisms
- **Quant researchers**: how LLM/Agents embed into factor mining, backtesting, and production risk control
- **AI-native engineers**: tracking frontier paradigms like Agent Harness and A2A protocol
- **Career switchers**: a practical path from Agent development to quant engineering
