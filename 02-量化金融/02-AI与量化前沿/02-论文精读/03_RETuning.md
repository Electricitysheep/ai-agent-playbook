# 论文精读 03：RETuning（arXiv 2510.21604）

> 精读日期：2026-08-09 ｜ 关联主题：主题 08（论文组）、主题 01（因子）、主题 06（另类数据）
> 关联知识库：主报告 §3.2（RETuning：推理时扩展用于股价预测，HKUST/弘量研究/IDEA）
> 代码：https://github.com/LinXueyuanStdio/RETuning

## 1. 基本信息

- **标题**：RETuning: Upgrading Inference-Time Scaling for Stock Movement Prediction with Large Language Models
- **作者**：Xueyuan Lin, Cehao Yang, Ye Ma, Ming Li, Rongjunchen Zhang, Yang Ni, Xiaojun Wu,
  Chengjin Xu, Jian Guo, Hui Xiong（**HKUST(GZ) / IDEA Research / 同花顺 Hithink / DataArc**）
- **发布**：2025-10-24（v1）｜ 领域：q-fin 股价预测
- 已投 OpenReview（2025-12-03）

## 2. 动机（解决什么问题）

1. LLM 在数学/代码上展现了推理时扩展（inference-time scaling，如多数投票）的价值，
   但金融任务（股价预测）未系统验证；
2. **两个观察到的缺陷**：
   - LLM 易被"上下文观点"带偏——跟着分析师观点走，而非独立系统分析（CoT 无独立逻辑）；
   - LLM 常罗列各源摘要而不权衡反方证据——对抗性证据对可靠预测至关重要。

**核心主张**：股价预测应是"生成式推理任务"（端到端处理所有文本源），
不是简单分类；需要冷启动方法（RETuning）解锁模型的独立推理。

## 3. 方法（怎么做的）

**RETuning = Reflective Evidence Tuning**（RL 之前的冷启动方法）：
生成 CoT 时鼓励模型：
1. **动态构建分析框架**（从多样信息源）；
2. **基于框架收集并给涨/跌证据打分**（而非基于上下文观点）；
3. **反思后给出预测**。

**数据集 Fin-2024**：覆盖 2024 全年 / **5,123 只 A 股** / **20 万+ 样本** / 平均输入 **32K tokens**
（长上下文）；六类异构信息源：新闻、基本面、分析师观点、量化因子报告、宏观、相似趋势股票。

## 4. 数据与实验设置

- **训练/评测**：Fin-2024（2024 全年，5123 只 A 股，20 万+ 样本）
- **任务**：三分类（up / hold / down）
- **扩展评测**：Fin-2025[June]（6 个月后样本外）+ OOD 股票
- **方法对比**：基线 LLM、RL（GRPO）课程设置、推理时扩展（多数投票 n=1~32）

## 5. 结果（作者如何验证有效）

1. **RETuning 有效解锁金融推理**：作为 RL 的冷启动，显著提升预测性能超强基线；
2. **推理时扩展有效但有限**：
   - 多数投票 n≈8-16 单调提升，之后**平台期甚至回退**；
   - RL（GRPO）提升单样本质量后，测试时扩展的必要性降低，**但不提升峰值准确率**；
3. **泛化性**：6 个月后（Fin-2025[June]）与 OOD 股票上推理时扩展仍有效——模型学到
   "股价预测的洞察"而非记忆；
4. 关键观察："**大多数 LLM 在股价预测上被随机猜测限制**"（多数基线≈随机），
   "涨/跌方向对 LLM 极其困难"。

## 6. 局限

1. **三分类准确率仍是核心指标**：即便优于基线，绝对准确率离"可交易"仍有距离
   （论文承认 up/down 极难预测）；
2. **推理时扩展收益有上限**（n≈16 后平台期）——不是"越多越好"；
3. A 股单市场，跨市场/高频未验证；
4. 32K 长上下文输入的推理成本高——生产部署需成本评估。

## 7. 与已有知识库报告的联系

- 主报告 §3.2：RETuning 是"推理时扩展用于股价预测"的代表（HKUST/弘量研究/IDEA）——
  与 Trading-R1（RL 对齐交易原则）、Fin-R1（小模型推理）构成 2025 年三条 LLM 交易路线；
- 主题 01（因子）：RETuning 的"证据打分"与 Chain-of-Alpha 的"四维评分"哲学一致——
  LLM 输出必须结构化、可评分、可检验；
- 主题 06（另类数据）：Fin-2024 的六源融合（新闻/分析师/量化因子/宏观/相似股）正是
  另类数据 + LLM 解析的工程化落地；
- 主题 02（TSFM）："多数投票 n≈16 平台期"与 TSFM"零样本非银弹"同构——
  都在说"技术有边界，别神化"。

## 8. 面试话术（30 秒）

"RETuning 是 HKUST/IDEA/同花顺的股价预测工作，核心发现两条：第一，冷启动方法
RETuning（反思式证据微调）能解锁 LLM 的金融独立推理——它发现 LLM 会被分析师观点带偏、
不会权衡反方证据，所以设计'构建框架→证据打分→反思'的 CoT 结构；第二，推理时扩展
（多数投票）在股价预测上**有效但有上限**——n=8-16 后平台期甚至回退。数据是 5123 只
A 股、20 万样本、32K 长上下文、六类信息源。我面试会强调它的诚实：承认大多数 LLM
在股价预测上接近随机，up/down 极难——这比吹 Sharpe 的论文可信得多。"
