## 5.1 是什么（30 秒版）

另类数据 = 传统行情/财报之外的一切数据源（新闻、电话会、社交媒体、卫星影像、信用卡交易、
地理定位）。**LLM 的作用是把这些非结构化文本变成可计算的因子**——情绪、事件类型、监管风险、
分析师分歧等。价值主张：这些因子与量价因子**低相关（正交）**，组合后提升 Sharpe；
但"另类数据 + AI"不是自动印钞机——Neudata 2026 报告显示机构买另类数据主要为了
**生产力提效（66%）而非策略优化（31%）**，且 LLM 情绪必须经过严格正交性/IC 检验才有价值。

## 5.2 为什么重要（行业证据）

- **市场规模**：Neudata 2026 报告——2025 年资管机构另类数据支出 **$28 亿（+17% YoY）**，
  2030 乐观情景 $23.1bn；网页抓取与交易数据为最大类别；平均每个数据集被约 20 家客户使用
  （2024 年 25 家，→ 数据集使用更分散而非更拥挤）（来源：Neudata 官方报告 + Business Insider，
  2026-02-23）。
- **LLM 情绪的学术证据**（arXiv 2604.13260《Which Voices Move Markets?》，2026）：
  FinBERT 解析 **650 万句 / 16,428 份 S&P 500 电话会记录（2015-2025）**，按发言者身份
  分段加权（分析师情绪权重 49% 最高）→ **样本外 Spearman IC 0.142**，月度多空组合
  **Fama-French 五因子 alpha 2.03%/月（t=6.49）**；且 FinBERT 完全吞并 Loughran-McDonald
  词典法（FinBERT t=5.90 vs LM t=0.86）；与标准化意外盈余（SUE）正交（双变量同显著）。
- **情绪 vs 结构化抽取**（arXiv 2607.28496《Beyond Sentiment》，2026）：LLaMA-3.1-70B 提取
  六维结构化特征（情绪极性/强度/事件类型/影响主体/时间跨度/置信度），与 FinBERT 情绪
  **53.5% 系统性分歧**；两者组合 F1 0.576→0.600（p<0.0001）——**把新闻压成一个情绪分
  会损失信息**，事件类型维度贡献（16.5%）与情绪本身（21.3%）相当。
- **市场摩擦下的情绪价值**（ACL EvalEval 2026，Kirtac）：973,481 条可交易新闻（2010-2026），
  5bps 交易成本下，**LLaMA-3 情绪策略 2024-06 至 2026-01 累计约 +180%**，词典法 -9%——
  高容量 LLM 在真实摩擦下仍保留经济价值，词典法不抗摩擦（来源：ACL Anthology 2026.evaleval-1.4）。
- **瑞士金融学院**（SFI 24-69，2024）：LLM + **市场驱动标签**（非人工标注）的情绪因子，
  多空组合年化 35.56%、Sharpe 2.21——标签方式比模型本身更影响结果。

## 5.3 怎么做（方法步骤 + 关键代码 + 踩坑点）

### 情绪/文本因子构造四步（LLM 管道）

```
1. 数据摄入：新闻 RSS / 电话会记录 / 财报 / 社交 → LLM 管道结构化（去重、去噪、对齐 ticker）
2. 情绪打分：FinBERT/LLaMA 逐句或逐条打分（比词典法语义更细）
3. 聚合：按时间（事件日）、按发言者（分析师/管理层权重不同）、按事件类型加权
4. 检验：自身 IC → 与量价相关性 → 偏相关（本实验落地）→ 衰减 → 组合增量
```

### 正交性验证管道（本实验已实现）

```python
# 检验 a：自身 IC/ICIR（逐日截面，t 日因子 vs t+h 收益）
# 检验 b：相关性矩阵（|corr(sentiment, mom20)| < 0.3 为初步正交）
# 检验 c：偏相关（两步残差：情绪与收益都投影掉量价因子后算相关）
A = np.column_stack([np.ones(len(m)), m["mom"], m["vol"]])
sent_clean = m["sent"] - A @ np.linalg.lstsq(A, m["sent"], rcond=None)[0]
ret_clean  = m["ret"]  - A @ np.linalg.lstsq(A, m["ret"], rcond=None)[0]
partial_ic = corrcoef(sent_clean, ret_clean)
```

### 踩坑点（面试高频）

1. **词典法 vs LLM 的差距巨大**：本实验词典法情绪 IC=-0.0047（弱），而论文 FinBERT 版本
   alpha 2.03%/月——"怎么做情绪"比"有没有情绪数据"更重要。
2. **时点对齐**：新闻情绪必须带时间戳对齐到交易日（本实验用"时点快照"是简化，真实管道
   要事件驱动对齐）；新闻去重（5 天余弦相似度 novelty screen，ACL 论文做法）。
3. **标签方法 > 模型架构**：市场驱动标签（SFI 24-69）优于人工标注——监督信号的定义决定上限。
4. **单一情绪分损失信息**：事件类型/影响范围/时间跨度是正交维度（2607.28496）——
   "多维文本表示"是 2026 前沿方向。
5. **成本与摩擦**：5bps 成本下词典法策略亏 9%、LLM 策略赚 180%——评估必须含摩擦。
6. **数据合规**：另类数据有许可/隐私问题（Lowenstein Sandler 报告），生产需法务审查。

## 5.5 我的可复现实验（做了什么/结果/结论）

**实验 06：情绪 vs 量价正交性验证**（✅ 运行成功，2026-08-09）
- **做了什么**：yfinance 拉 20 只美股 2 年日线 + Google News RSS 拉新闻标题，词典法情绪打分
  （Loughran-McDonald 风格词表），跑完整正交性管道：自身 IC → 相关性 → 偏相关。
- **结果**：
  1. 正交性成立：|corr(情绪,mom20)|=0.033、|corr(情绪,vol20)|=0.147（低相关）；
  2. 词典法情绪自身 IC=-0.0047（弱）——诚实结果，印证"词典法在 LLM 面前已过时"；
  3. 偏相关 -0.0105（控制量价后仍弱），说明弱情绪信号的增量有限。
- **结论**：正交性验证管道跑通（面试可讲三步法）；词典法情绪弱 + 论文 LLM 情绪强（alpha
  2.03%/月）的对比，正好说明"LLM 语义提取"是另类数据价值的放大器。局限：时点快照、小样本、
  未测衰减（真实管道需完整事件时间线）。

## 5.6 面试话术

**30 秒故事**：
"我研究了另类数据 + LLM 解析这条线，做了个正交性验证实验：拉 20 只美股行情和 Google News
新闻，用词典法做情绪因子，跑'自身 IC → 与量价相关性 → 偏相关'三步管道。结果是情绪与动量、
波动率相关只有 0.03 和 0.15——正交性成立，文本信息确实和价量互补。同时我读到两个关键证据：
FinBERT 电话会情绪月 alpha 2.03%（t=6.49）而且完全吞并词典法；LLaMA 情绪策略在 5bps 成本下
两年赚 180% 而词典法亏 9%。结论是：另类数据 + LLM 是真实的新信息源，但'怎么做情绪'
（模型+标签+聚合方式）决定了价值，且必须过正交性/IC 检验才能上库。"

**3 个数字**：
1. **0.03 / 0.15**：我实测情绪与动量/波动率的相关性（正交）
2. **2.03%**：FinBERT 电话会情绪的月 alpha（t=6.49，FF5 调整）
3. **$28 亿 / +17%**：2025 年另类数据支出与增速（Neudata 2026）

**可能的追问与应答**：
- Q：为什么词典法情绪不显著、FinBERT 显著？
  A：词典法把语义压成关键词匹配，错过多义/反讽/上下文（如"风险可控"含正负词）；FinBERT
  是金融域预训练 Transformer，能建模上下文。论文证据：FinBERT 完全吞并词典法（联合回归中
  词典法系数 t=0.86 不显著）。LLM 版更进一步（2607.28496：六维结构化特征）。
- Q：另类数据怎么和你的量价因子结合？
  A：先正交性检验（低相关才进库），再走主题 01 的三道检验（IC/衰减/互补性），最后进
  LightGBM 多因子合成或作为 Qlib 的 StaticDataLoader 特征列（主题 05）——LLM 产出"特征"
  而非"结论"，保证可检验性。
- Q：数据成本与合规？
  A：新闻/社交免费公开（RSS/API），电话会/卫星/信用卡是商业数据（$28 亿市场、$1M/$1B
  AUM 基准）；合规要点：许可审查（Lowenstein）、隐私（GDPR/PIPL）、新闻去重防冗余。
- Q：情绪因子的衰减特性？
  A：电话会情绪通常在事件后 1-5 日衰减（价格渐进吸收软信息，2604.13260 的 CAR 图）；
  日频新闻情绪衰减更快。衰减测试决定调仓频率与成本预算。
