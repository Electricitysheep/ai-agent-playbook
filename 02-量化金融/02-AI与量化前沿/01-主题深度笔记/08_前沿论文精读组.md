## 5.1 是什么（30 秒版）

2025-2026 年 LLM 量化四条前沿路线：
1. **Trading-R1**（2509.11420）：SFT+RL+三阶段课程让 LLM 推理对齐交易原则——解决
   "有推理能力但无交易纪律"；
2. **Fin-R1**（2503.16252）：7B 小模型 SFT+GRPO 两阶段训练达金融推理 SOTA——证明
   "小模型+高质量数据+RL 能打大模型"；
3. **RETuning**（2510.21604）：推理时扩展用于股价预测——冷启动反思证据微调 +
   "多数投票有效但有上限"；
4. **LLM 综述**（2605.05211，IEEE 2026）：对冲基金视角把 LLM 应用归四类、警示六大陷阱。
共同底色：**LLM 在金融的价值在"结构化可解释的辅助推理"，不在"端到端替代"**。

## 5.2 为什么重要（行业证据）

- **四条路线构成行业全景**（主报告 §3.2）：因子挖掘（Chain-of-Alpha/RD-Agent）、
  交易推理（Trading-R1）、金融推理（Fin-R1）、股价预测（RETuning）——
  面试能分清楚这四条线，就证明你不是"只会背模型名"。
- **关键证据（作者如何验证有效）**：
  - Trading-R1：6 只股票/ETF 端到端交易模拟，风险调整收益与回撤优于全基线
    （⚠ 样本小、未披露多重检验控制）；
  - Fin-R1：5 个金融推理基准平均 75.2 分（仅次 671B DeepSeek-R1 78.2），
    FinQA/ConvFinQA 双第一（76.0/85.0），同规模超 17 分——**表格化对比是
    "验证有效"的标准做法**；
  - RETuning：5123 只 A 股/2024 全年/20 万+ 样本/32K 长上下文；多数投票 n≈8-16
    单调提升后平台期；6 个月后 OOD 仍有效——**大样本 + 时间外推验证**；
  - 综述：无新实验，价值在"四类应用 + 六大陷阱"框架（情绪脆弱/数据泄漏/流动性溢价/
    可预测性极限）。
- **行业含义**：Fin-R1（推理 SOTA）与 Trading-R1（交易对齐）验证"RL 能让 LLM 更
  专业"；RETuning 验证"推理时扩展在金融有边界"——三条线的共识：**金融需要
  结构化、可解释、有纪律的 LLM，不是自由发挥的 LLM**。

## 5.3 怎么做（方法步骤 + 关键代码/prompt 模式 + 踩坑点）

### 四篇必读的"验证有效性"方法论（面试重点）

| 论文 | 验证方式 | 你可以学到的"验证范式" |
|---|---|---|
| Trading-R1 | 端到端交易模拟（收益/回撤） | 不只报准确率，报投资结果 |
| Fin-R1 | 5 基准表格 + 消融（Zero/SFT/Full） | 表格化对比 + 消融证明每一步的必要性 |
| RETuning | 大样本 + OOD 时间外推 + scaling 曲线 | 测边界（n 多少开始平台期）比测峰值更诚实 |
| 综述 | 框架性总结（四类+六陷阱） | 面试答题框架本身 |

### 核心方法速记

```
Trading-R1:  SFT(交易原则) → RL(三阶段课程: 简单信号→波动率调整→综合论文)
Fin-R1:      SFT(60,091 条蒸馏 CoT) → GRPO(格式奖励+准确率奖励+模型验证器)
RETuning:    Cold-start(构建框架→证据打分→反思) → RL → 推理时扩展(多数投票 n≈8-16)
综述:        四类应用(新闻情绪/财报分析/价格token化/多智能体) + 六大陷阱
```

### 踩坑点（面试高频）

1. **推理题 ≠ 交易能力**：Fin-R1 是 FinQA/ConvFinQA 的 SOTA，但不等于可交易 alpha——
   面试主动区分这两个概念是成熟度信号；
2. **小样本结论谨慎**：Trading-R1 仅 6 只股票，未披露 DSR/PBO——用主题 07 框架审视；
3. **scaling 有上限**：RETuning 实测 n≈16 后平台期——"推理时扩展越多越好"是误区；
4. **LLM 会被分析师观点带偏**（RETuning 观察）：CoT 无独立逻辑、不权衡反方证据——
   需要结构化提示（构建框架→证据打分→反思）而非自由发挥。

## 5.6 面试话术

**30 秒故事**：
"我精读了 2025-26 年四条 LLM 量化前沿路线：Trading-R1 用 SFT+RL 三阶段课程让 LLM
推理对齐交易原则；Fin-R1 用 7B 小模型 SFT+GRPO 打到金融推理 75.2 分、只比 671B
大模型低 3 分；RETuning 用反思证据微调解锁推理时扩展，5123 只 A 股上多数投票
n≈16 后平台期；还有一篇对冲基金视角综述把 LLM 应用归成四类、警示六大陷阱。
我的判断：四条线的共识是 LLM 在金融的价值在'结构化、可解释、有纪律的辅助推理'，
不在端到端替代——而且 Fin-R1 是推理题 SOTA、不等于交易能力，这个区分面试官
一听就知道你真的读过。"

**3 个数字**：
1. **75.2 vs 78.2**：Fin-R1（7B）vs DeepSeek-R1（671B）金融推理平均分
2. **10 万样本/18 个月**：Trading-R1 训练语料规模
3. **n≈8-16 平台期**：RETuning 推理时扩展的有效上限

**可能的追问与应答**：
- Q：四条路线你选哪条深入？
  A：如果做研究，我选 RETuning 的思路——它最诚实（承认大多数 LLM 在股价预测上
  接近随机、承认 scaling 有上限），且 A 股大样本方法论可以直接迁移到我的实习因子管道；
  如果做生产，我选 Fin-R1 的小模型路线——部署成本低、可解释输出。
- Q：这些论文的共性局限？
  A：三个——推理基准 ≠ 交易收益（Fin-R1）；小样本 + 无多重检验控制（Trading-R1）；
  单一市场/单一频率（RETuning 只有 A 股日频）。我的解法：所有结论用主题 07 的
  DSR/PBO 框架复核，用实验 01 的三道检验落地到因子。
- Q：LLM 推理时扩展和 TSFM 的边界？
  A：RETuning 证明推理时扩展在金融有上限（n≈16 平台期），TSFM 综述证明零样本不是
  银弹——两者同构：技术有边界，别神化。金融的正确姿势是"结构化检验 + 领域适配"。
