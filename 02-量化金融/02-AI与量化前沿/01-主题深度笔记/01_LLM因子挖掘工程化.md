## 5.1 是什么（30 秒版）

LLM 因子挖掘 = 用大模型把"数据字段 + 数学算子"组合成可解释的候选 alpha 因子公式，
再经过**严格检验管道**（IC/ICIR → 衰减 → 互补性）筛选入池。
它不替代人的经济直觉，而是把"因子空间搜索"自动化——2026 年行业已从"人写因子"进化到
**"人给想法/LLM 写公式/管道检验"**（Alpha-GPT 的人机交互范式）和 **"LLM 全自动生成-评估-精修"**
（Chain-of-Alpha 双链范式）。价值在**检验纪律**，不在生成本身。

## 5.2 为什么重要（行业证据）

- **价值定位**：主报告五环节价值图中，"因子"环节 AI 增量价值 = **高（年化 1-3% alpha，低相关）**，
  生产就绪度 ✅。LLM 提取的语义因子（管理层情绪 delta、电话会语气波动、监管风险评分、分析师修正分歧）
  是传统量价/基本面因子看不到的新维度（来源：主报告 §3.1，2026-04）。
- **Alpha-GPT 实证**（EMNLP 2025 Demo，作者 Saizhuo Wang / Hang Yuan / Leon Zhou / Lionel Ni /
  Heung-Yeung Shum / Jian Guo）：WorldQuant International Quant Championship 2024 中
  **top-10 / 41000+ 支队伍**；人机交互迭代使因子 IC 从 0.58% → 1.23%（search enhancement）→
  2.23%（1 轮交互 + 增强），IC 提升显著（来源：ACL Anthology 2025.emnlp-demos.14，2025-11）。
- **Chain-of-Alpha**（arXiv 2508.06312，Lang Cao，SCITIX）：CSI 500 上 AR 0.1324 / IR 1.4178，
  CSI 1000 上 AR 0.1471 / IR 1.4043，**12 项指标中 10 项最优**，超越经典库（Alpha 101/158/360）、
  传统方法（GP/DSO/AlphaGen/AlphaForge）与 LLM 基线（LLM+CoT/ToT/MCTS）；
  双链消融：去掉优化链 AR 0.1471→0.1346，去掉生成链 RankIC 0.0902→0.0847。
  **⚠ 重要警示：该论文已于 2025-08-28 被 arXiv 撤回**（提交者当时无许可权同意 license），
  内容快照（ar5iv/alphaXiv）仍可读，但引用需注明"已撤回、内容待核"。
- **FactorMAD**（ACM ICAIF 2025，Yitong Duan / Chuheng Zhang / Jian Li）：双 LLM agent 结构化辩论
  迭代精化因子，代码型因子流水线（生成→验证→修正→评估），100 trials/10 rounds 设定下
  多智能体辩论的 IC 提升显著优于单 agent（来源：DOI 10.1145/3768292.3770377，2025-11）。
- **RD-Agent / 融量 AlphaMind**：国内 6 个国产大模型同台 20 轮迭代挖换手率反转因子（来源：新浪财经，2026-05-08，二手）。

## 5.3 怎么做（方法步骤 + 关键代码/prompt 模式 + 踩坑点）

### 管道总览（三道检验是红线，不可跳过）

```
LLM 生成候选因子公式
   ↓ 解析为可执行代码（eval 沙箱 / pandas 表达式）
[检验1] IC / RankIC / ICIR（截面相关 + 时间稳定性）
[检验2] 衰减测试（IC 随持有期 h 的变化）
[检验3] 互补性（与已入选因子池的相关 < 阈值）
   ↓
通过 → 因子池（Fe）   淘汰 → 废弃池（Fd，作为负面示例喂回 LLM）
```

### Chain-of-Alpha 四维评分（Score=[S,C,E,D]，已落地到本实验）

- **S Strength** = 截面 RankIC（预测力）
- **C Consistency** = RankICIR = mean(RankIC)/std(RankIC)（时间稳定性）
- **E Efficiency** = 1/Turnover（换手越低越好，交易成本）
- **D Diversity** = 1 - min_corr(f, f_k) 对所有已入池 f_k（互补性）

### 因子生成 Prompt 模式（含反例）

```
【正向模板】
你是量化研究员。基于可用字段 {open,high,low,close,volume,amount} 和算子
{rank,delta,correlation,covariance,ts_mean,ts_std,ts_rank,ts_argmax,scale,power}，
生成一个可解释的 alpha 因子表达式（仅用 t 日及之前数据，禁止未来信息）。
要求：1) 有明确经济学逻辑并说明；2) 表达式可解析执行；3) 输出 JSON：{"name","expression","logic"}。

【反例（要避免的 prompt）】
- "随便生成几个赚钱的因子" → 无字段/算子约束，LLM 会产出不可执行或未来函数的垃圾
- "帮我找一个 alpha 让回测 Sharpe 最高" → 直接优化回测指标=数据挖掘，必过拟合
- 不给废弃池（Fd）示例 → LLM 会重复生成已被证明无效的因子
```

### 三道检验的工程落地（对应本实验 main.py）

```python
# 检验1：逐日截面 IC（因子 t 日值 vs 未来 h 日收益；杜绝前视）
fwd_ret = close.shift(-h) / close - 1          # t→t+h 收益
ic_t = corrcoef(factor_t, fwd_ret_t)           # 每日一个截面相关
ic, icir = ic.mean(), ic.mean()/ic.std()       # 平均与稳定性
# 检验2：衰减 = 对 h∈{1,5,10,20} 重复检验1，看 IC 是否随时间衰减
# 检验3：互补性 = 因子值 stacked 后的相关矩阵，|r|>阈值(如0.6)判冗余
```

### 踩坑点（面试高频）

1. **前视陷阱**：因子用了 t 日数据，标签必须 t→t+h；若框架把当日收益也算进标签，
   "动量类"因子 IC 会伪造到 ≈1（本实验实测：h=0 时 IC=1.0000，h=1 时 -0.0355）。
2. **小样本假象**：20 只股票 × 485 天，单因子 IC 噪声巨大，全部因子都过不了 0.02 阈值是正常的；
   实盘需要全市场/指数成分 + 5 年+ 历史 + 行业中性化。
3. **同一数据多假设检验**：LLM 一个月能生成成百上千信号（Man Group 官方承认），
   多重检验必然出现"运气因子"——需 PSR/Deflated Sharpe（见主题 07）。
4. **LLM 输出不可控**：必须用"结构化输出 + 解析校验 + 沙箱执行"（FactorMAD 的 validation/correction 阶段），
   防止代码注入或语法错误直接进回测。
5. **生成公式 ≠ 有效因子**：因子池要有经济学解释（Alpha-GPT 强调"可解释 alpha"），
   "AI 提取的"不是绿灯（主报告方法论红线）。

## 5.5 我的可复现实验（做了什么/结果/结论）

**实验 01：LLM 因子三道检验管道**（✅ 运行成功，2026-08-09）
- **做了什么**：用 yfinance 拉 20 只 A 股大盘股 2 年日线（485 交易日），构造 9 个候选因子
  （7 个经典量价 + 1 个模拟噪声 + 1 个前视伪造），跑完整 IC/ICIR → 衰减 → 互补性 → 筛选管道。
- **结果**：
  1. 前视演示：lookahead 因子 h=0 时 IC=1.0000（伪造），h=1 时 IC=-0.0355（真实）——前视检验的杀伤力直观可见；
  2. 全部 9 因子未过阈值（IC<0.02/ICIR<0.25）→ 0 通过——小样本的正确表现；
  3. 衰减：mom20 的 IC 随 h 上升（0.008@h1 → 0.048@h10），vwap_dev 在 h=10/20 达 0.058；
  4. 互补性：mom20×vwap_dev 相关 0.84、vol20×high_low 相关 0.83 冗余明显。
- **结论**：管道正确性已验证；小样本下"全淘汰"是诚实结果，真实落地需全市场股票池 +
  行业中性化 + 成本建模。实验仅验证方法学，不构成因子有效证据。

## 5.6 面试话术

**30 秒故事**：
"我在实习里做了 54 个因子的工程管道，后来研究 LLM 因子挖掘时发现行业红线是'生成不重要、检验才重要'。
我把 Chain-of-Alpha 的四维评分（IC/ICIR/换手/互补性）和 Alpha-GPT 的人机交互范式落地成了一个可运行管道：
9 个候选因子（含故意注入的前视因子和噪声因子）跑 IC→衰减→互补性三道检验。
最直观的发现是前视陷阱——同一个因子，用 t 日数据配 t 日收益，IC 能伪造到 1.0；错位到 t+1 就变成 -0.04。
这道检验比任何模型都重要，它决定了回测是真相还是幻觉。"

**3 个数字**：
1. **1.0000 vs -0.0355**：前视/正确错位下同一因子的 IC（我实测）
2. **0.58% → 2.23%**：Alpha-GPT 人机交互迭代对因子 IC 的提升（EMNLP 2025）
3. **1-3%**：文本因子在美股贡献的年化 alpha（Lopez de Prado/AQR 口径）

**可能的追问与应答**：
- Q：LLM 生成的因子怎么防止过拟合？
  A：三道检验 + 多重检验校正（Deflated Sharpe，见主题 07）+ 样本外 walk-forward + 经济逻辑审查；
  另外把"已验证无效"的因子放进废弃池喂回 LLM，避免重复探索。
- Q：为什么不用 LLM 直接输出完整策略而只输出因子？
  A：因子是可解释、可检验、可组合的最小单元；完整策略黑箱化后无法归因，
  且行业证据（主报告）表明 LLM 的价值在因子与数据层，不在端到端选股。
- Q：Chain-of-Alpha 被撤回你怎么看？
  A：撤回原因是提交者许可权问题而非内容造假，但作为候选人我引用时会注明"已撤回、内容快照待核"，
  并且我会用自己跑的三道检验管道独立验证其思想（双链 + 四维评分），不依赖论文背书。
- Q：IC 阈值怎么定？
  A：依频率与股票池而定：日频全市场通常 |IC|>0.02-0.03 才值得看，ICIR>0.3-0.5 才够稳；
  小样本下阈值要更保守，或用 t 检验看 IC 是否显著区别于 0。
