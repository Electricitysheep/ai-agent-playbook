## 5.1 是什么（30 秒版）

最优执行（optimal execution）= 把大单拆成小单、在"冲击成本"（卖太快价格被打下去）和
"时序风险"（卖太慢价格可能漂移）之间做权衡。Almgren-Chriss（2000）给出闭式解：
持仓路径是 sinh 曲线，风险厌恶 λ 决定前倾程度（λ=0→TWAP，λ→∞→立即清仓）。
RL 执行 = 用强化学习在模拟环境里学"何时卖多少"的自适应策略，而不是固定切片。
**这是 RL 在量化里最成熟、最被低估价值的应用**——主报告五环节价值图中"执行"环节
AI 增量价值 = **高（市场冲击 -10~30%）**，生产就绪度 ✅（Citadel、JP Morgan 已生产运行）。

## 5.2 为什么重要（行业证据）

- **价值定位**：大单市场冲击降低 **10-30%**（vs 启发式调度）；JP Morgan、Citadel 已生产运行
  RL 执行引擎（来源：主报告 §5，AgentPit 从业者综述，2026-04）。
- **为什么执行是 RL 的好场景**（主报告 §5）：奖励信号稠密（成交成本可直接度量）、
  环境相对平稳（订单簿微观结构）、状态空间可控（库存/时间/盘口）——恰好避开 RL 在
  选股场景的所有痛点（稀疏奖励+非平稳+高维）。
- **JP Morgan 论文**（Vyetrenko & Xu，AI Research）：LOB 模拟器（从历史数据合成市场对
  激进交易的响应）+ 风险敏感 Q-learning + 决策树策略：**执行成本节省 32%**，代价是成本
  标准差 +27%——风险-收益权衡的实证（来源：jpmorgan.com AI research PDF）。
- **QRM + DDQN**（arXiv 2511.15262，Espana/Lillo 等）：Queue-Reactive Model 模拟限价订单簿，
  DDQN agent 在 5 层×30 单元网络上 50 万 episode 训练（600 秒、25 切片、25 股），
  在时间/库存/价格/深度状态上**持续优于 TWAP 等标准基准**，学会等待有利流动性条件
  （来源：arXiv 2511.15262，2025）。
- **ICAIF 2025**（ACM 10.1145/3768292.3770405）：RL 执行策略（香港恒指数据，模拟器评估）
  在 Almgren-Chriss 效率前沿上比 TWAP/VWAP 基线**更接近最优前沿**；slippage 目标下的
  双峰策略接近 λ=0 最优点；并指出 EU AI Act 可解释性要求（决策树策略的可解释优势）
  （来源：ACM ICAIF 2025）。
- **中国市场**：券商极速柜台与智能拆单成标配；2026 竞争焦点从"模型"转向"执行效率与
  智能化治理"（主报告 §5，华泰等研报）。

## 5.3 怎么做（方法步骤 + 关键代码 + 踩坑点）

### 步骤 1：AC 闭式解（教科书基线，面试必会）

```
价格动态：S_k = S_{k-1} + σ√τ·ξ_k − τ·γ·v_k   （永久冲击 γ）
执行价：  S̃_k = S_k − η·v_k                    （临时冲击 η）
目标：    min E[C] + λ·Var[C]
最优持仓：x_k = X·sinh(κ(T−t_k)) / sinh(κT)，κ = √(λσ²/η)
```

- λ=0 → κ=0 → 线性清算（TWAP）；λ→∞ → 立即清算
- 永久冲击只平移总成本（½γX²），不改变轨迹形状；只有临时冲击和风险交互决定曲线

### 步骤 2：RL 执行智能体（状态/动作/奖励设计）

```python
# 状态：剩余库存、剩余时间、当前价格（可选订单簿深度/失衡）
# 动作：卖出剩余库存的比例 {0%, 20%, ..., 100%}
# 奖励：-成交成本 - λ·σ²τ·(剩余库存)²   ← 风险项必须与成本同量级，否则学偏
# 环境：LOB 模拟器（生产）或 AC 模型（教学）；最后一步强制清仓（期限约束）
```

### 踩坑点（本实验实际踩到）

1. **奖励量级失衡**：风险惩罚 σ²τ·inv² 若不与成本归一化，Q 学习会退化为"第一步全卖"
   （std=0，策略无意义）或"拖延到最后一刻"（成本=0 是局部最优）。
2. **必须强制期限约束**：不强制最后清仓，agent 会学到"不卖"——执行问题本质是
   fixed-endpoint 问题（QT=0）。
3. **环境与评估不一致**：训练环境和评估环境必须用同一套成本逻辑（本实验初始版本
   训练环境成本不含价格随机漂移，导致评估 std=0 假象）。
4. **AC 参数敏感性**：κ=√(λσ²/η)，η 太小会让 κ 爆炸（λ=0.5 就全清仓）；
   效率前沿要有区分度需 η 与 σ² 同量级。
5. **线性冲击 vs 现实**：真实冲击亚线性（平方根定律）；RL 的价值正在于不需要
   假设冲击函数形式（模型无关）。

## 5.5 我的可复现实验（做了什么/结果/结论）

**实验 03：AC 闭式解 + Tabular Q-Learning 执行对比**（✅ 运行成功，2026-08-09）
- **做了什么**：实现 AC 模型（永久+临时冲击、E[C]+λVar[C]），蒙特卡洛验证 λ∈{0,0.1,0.5,2,10}
  的效率前沿；训练 Tabular Q-Learning（11 库存桶×11 时间×6 动作），对比 TWAP/AC/Q 学习。
- **结果**：
  1. AC 三大性质全部验证：λ=0→首切片 1.00x TWAP；λ=10→9.16x（前倾）；std[C] 单调 3952→2008；
  2. Q-Learning 学到 E[C]=498K（+24.5% vs TWAP）但 std[C]=3277（−16%）——站在效率前沿
     稍前倾位置，用少量冲击成本换显著更低风险；
  3. 踩坑记录：奖励量级失衡→全卖/拖延退化；无期限约束→"不卖"；环境不一致→std=0 假象。
- **结论**：AC 是执行优化的教科书基线；RL 能学会状态自适应的风险-成本权衡——
  验证了"RL 在执行上 work"（奖励稠密+环境平稳+状态可控）。局限：AC 简化环境，
  生产需 LOB 模拟器（JPM/QRM 范式）。

## 5.6 面试话术

**30 秒故事**：
"我实现了 Almgren-Chriss 最优执行模型并用 Tabular Q-Learning 训练执行智能体。
AC 闭式解的三大性质我全部验证过：风险厌恶 λ=0 时退化成 TWAP，λ 增大时持仓路径前倾
（首切片从 1x 涨到 9x），冲击成本上升但时序风险下降——这就是'无免费午餐'。
然后我用 Q 学习学'何时卖多少'，它学会站在效率前沿上：成本比 TWAP 高 24% 但风险低 16%。
这让我理解了为什么执行是 RL 在量化里最成熟的应用——奖励稠密、环境平稳、状态可控，
和 RL 选股那种稀疏奖励+非平稳的烂场景完全不同。JPM 的论文也报告 RL 执行节省 32% 成本，
Citadel 和 JPM 都已生产运行。"

**3 个数字**：
1. **10-30%**：RL 执行降低大单市场冲击的幅度（行业生产经验）
2. **32% vs +27%**：JPM 风险敏感 RL 的成本节省与风险代价
3. **124.5% vs 84%**：我实验里 Q 学习相对 TWAP 的成本/风险（E[C] 124.5%、std[C] 84%）

**可能的追问与应答**：
- Q：为什么 RL 在执行上 work、在选股上不行？
  A：三点——奖励密度（执行每步有成交成本可度量，选股奖励稀疏且滞后）、
  环境平稳性（微观结构相对稳定，市场非平稳）、状态可控（库存/时间是马尔可夫的，
  选股状态高维且部分可观测）。主报告也把"RL 选股"列为要高度怀疑的环节。
- Q：AC 模型的核心假设和局限？
  A：假设线性冲击、算术布朗运动价格、恒定波动。局限：真实冲击是亚线性的（平方根定律），
  价格有跳跃和漂移。Almgren 2003 推广了非线性冲击。RL 的价值之一就是不需要假设冲击形式。
- Q：RL 执行训练环境从哪来？
  A：生产级用 LOB 模拟器（JPM 从历史数据合成市场响应；QRM 用状态依赖订单流强度建模），
  关键是不能用历史数据回放——历史数据无法响应你的交易决策（反事实缺失），
  必须用能对 agent 动作产生反应的模拟器。
- Q：怎么评估执行质量？
  A：实现缺口（implementation shortfall）vs 基准（TWAP/VWAP/AC）；站在 AC 效率前沿的
  距离是统一度量（ICAIF 2025 的方法）；上线前必须回测→模拟→小仓→全量四步。
