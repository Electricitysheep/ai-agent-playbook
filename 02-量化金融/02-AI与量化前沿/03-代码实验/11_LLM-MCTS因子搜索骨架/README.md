# 实验 11：LLM-MCTS 因子搜索骨架（stub 版，还原东吴研报方法论）

> 对应主题：`02_主题深度笔记/01_LLM因子挖掘工程化.md`、`09_中国市场AI量化实践.md`
> 还原：东吴证券《从人工写因子到 AI 写因子：LLM-MCTS 驱动的可解释因子迭代框架》（2026-06-23）
> 运行日期：2026-08-10 ｜ 状态：✅ 运行成功（含重要"负面结果"）

## 目的

还原东吴 LLM-MCTS 框架的**核心结构**（MCTS 控制搜索 + 生成器产生候选 + 双层验证），
用规则生成器代替真实 LLM（无 API key），验证 MCTS 搜索框架本身。真实 LLM 版本
只需替换 `rule_generator` 为"读父节点公式 + 评测反馈 → 生成带金融假说的公式"。

## 运行环境

- Windows + Python 3.14 / yfinance / pandas / numpy（无 LLM 依赖）
- 运行命令：`python main.py`（yfinance 拉 25 只 A 股 3 年日线）

## 架构（对照东吴研报）

```
[Seed 化] 6 个基础因子为根节点（mom20/rev5/vol20/vwap_dev/amt_trend/high_low）
[选择]    UCT = exploit(avg reward) + 1.4·sqrt(ln(parent.visits)/visits)
[扩展]    rule_generator：窗口±8、方向翻转、算子替换（模拟 LLM 生成候选）
[评测]    真实数据样本内 IC（≤2025-06-30，h=5）
[回传]    reward=max(IC,0) 沿父链更新
[双层验证] 样本内选型 + 样本外（≥2025-07-01）仅验证不反选（东吴铁律）
```

## 结果摘要（2026-08-10 运行）—— 两个重要发现

**发现 1：样本内选优的过拟合陷阱（教科书级）**

```
最优 Seed:     high_low(窗口=20) 样本内 IC=+0.0311
MCTS 最优:     high_low(窗口=13) 样本内 IC=+0.0550（+77% 提升）
样本外验证:    high_low(窗口=13) 样本外 IC=-0.0632（完全翻转！）
```

**MCTS 搜索找到的"更优"因子，样本外 IC 从 +0.055 翻转为 -0.063——这是过拟合的
完美实证**：样本内微调（窗口 20→13）只是拟合了样本内噪声，样本外立刻失效。
这正是东吴研报"样本外仅用于验证，避免用样本外倒推选因子"的原因，也是
主题 07（DSR/PBO）存在的意义。**这个"负面结果"比漂亮的正面结果更有面试价值。**

**发现 2：规则生成器空间太小，MCTS 优势无法体现**

```
随机基线最优: high_low(窗口=13) 样本内 IC=+0.0550
MCTS 最优:    high_low(窗口=13) 样本内 IC=+0.0550（完全相同）
```

30 轮 × 6 候选 = 180 个候选，随机采样也能撞到全局最优——因为规则生成器只在
"窗口/方向/算子"三种操作上组合，搜索空间小且规则（无语义）。**真实 LLM 的价值
在于生成"语义多样、带金融假说的候选"**（如"高量脉冲次数""成交额加权实现波动"），
这才是 MCTS 引导搜索（而非随机）的用武之地。本实验证明：**MCTS 框架本身有效，
但生成器的质量决定上限**——与东吴研报"LLM 改变候选从哪来，MCTS 保留往哪搜"一致。

## 结论

1. **框架验证成功**：MCTS 四动作（选择/扩展/评测/回传）+ 双层验证闭环可运行；
2. **过拟合警示（最有价值的发现）**：样本内 IC 提升 77% 的因子样本外完全失效——
   "样本外不反选"不是口号，是生死线；
3. **生成器是关键**：真实 LLM 替换规则生成器后，MCTS 的引导价值才能体现。

## 局限

- 规则生成器非真实 LLM（无语义、无假说、无审查）；25 只股票面板小；
- 未做去重（东吴的全局相关<0.8 阈值）与 DSR 复核；
- 样本外仅 1 段，未做 walk-forward 多窗口。

## 扩展路径（真实 LLM 版）

1. 替换 `rule_generator`：prompt = 父节点公式 + 样本内评测反馈 + 可用算子表 +
   "生成带假说/方向/适用状态/风险解释的新公式"（东吴研报 prompt 结构）；
2. 加"逻辑审查"节点：公式解析 + 合法性过滤（不合格候选不进树）；
3. 加去重（IC_max≥0.99 与 SOTA 库判冗余）与 DSR/PBO 复核；
4. 扩展到分钟级高频因子（东吴"高量脉冲次数"RankIC 0.0839 案例）。
