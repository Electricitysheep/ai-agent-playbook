# 实验 12：walk-forward 完整实现（滚动窗口 + IS/OOS 过拟合诊断）

> 对应主题：`02_主题深度笔记/07_回测纪律与过拟合诊断.md`
> 运行日期：2026-08-10 ｜ 状态：✅ 运行成功（结果极具教学价值）

## 目的

把主题 07 的 walk-forward 理论落地为可运行代码：
1. 滚动窗口"训练→冻结参数→OOS 只测一次→滚动前进"的完整实现
2. **IS vs OOS IC 对比**——验证"OOS < 50% IS = 曲线拟合"判据
3. walk-forward vs 单次分割的诚实度对比

## 运行环境

- Windows + Python 3.14 / lightgbm 4.7 / sklearn / yfinance
- 运行命令：`python main.py`（yfinance 拉 25 只 A 股 3 年日线 + LightGBM 训练）

## 设置

- 数据：25 只 A 股 3 年日线（662 交易日），16,550 行面板样本
- 因子：6 个基础量价因子（mom20/rev5/vol20/vwap_dev/amt_trend/high_low）
- 模型：LightGBM（50 棵树，max_depth=3），预测 h=5 日收益
- walk-forward：IS 窗口 180 天 / OOS 窗口 60 天 → 8 个独立窗口

## 结果摘要（2026-08-10 运行）—— 教科书级过拟合演示

**每窗口 IS vs OOS IC（OOS/IS < 0.5 = 曲线拟合）：**

| 窗口起点 | IS IC | OOS IC | OOS/IS | 判定 |
|---|---|---|---|---|
| 2024-08-08 | +0.318 | -0.024 | -0.08 | ⚠曲线拟合 |
| 2024-11-11 | +0.404 | +0.114 | 0.28 | ⚠曲线拟合 |
| 2025-02-12 | +0.439 | +0.060 | 0.14 | ⚠曲线拟合 |
| 2025-05-13 | +0.431 | -0.045 | -0.10 | ⚠曲线拟合 |
| 2025-08-06 | +0.359 | -0.102 | -0.29 | ⚠曲线拟合 |
| 2025-11-06 | +0.361 | -0.056 | -0.15 | ⚠曲线拟合 |
| 2026-02-02 | +0.347 | -0.088 | -0.25 | ⚠曲线拟合 |
| 2026-05-11 | +0.333 | +0.017 | 0.05 | ⚠曲线拟合 |

**8/8 窗口全部曲线拟合**——这是过拟合的完美实证：
- IS IC 普遍 0.32-0.44（模型在训练集内"记住"了噪声，有监督拟合天然虚高）
- OOS IC 几乎全负（-0.10 ~ +0.11）——样本外完全失效
- **结论：该因子+模型组合在该股票池上无真实预测力——walk-forward 8 个窗口全失败 = 诚实告知"不可用"，这正是它的价值**

**对比：单次分割 OOS IC = -0.0378**（也是负的）——两种方法都诚实显示无 alpha，但 walk-forward 多给了 8 个独立窗口的证据。

## 核心结论（面试直接讲）

1. **walk-forward 是"诚实裁判"**：8 个独立 OOS 窗口全失败，比单次分割更有说服力地证明"这策略不可用"——面试讲"我跑过 walk-forward，8 个窗口全过拟合"比"我回测 Sharpe 2"可信得多。
2. **IS IC 虚高是机器学习的本性**：有监督模型在训练集内必然高 IC（0.3+），样本外衰减——所以"样本内 IC"从来不是证据，"OOS 稳定性"才是。
3. **工程要点**：预处理（归一化）必须在 IS 上 fit、OOS 只应用（全局统计=泄漏）；每窗口结果持久化（JSONL：窗口ID/参数/指标/版本）保证可复现；≥3-5 窗口才有统计意义。
