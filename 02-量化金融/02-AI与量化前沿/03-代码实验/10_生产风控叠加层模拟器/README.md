# 实验 10：生产风控叠加层模拟器（LLM 幻觉拦截验证）

> 对应主题：`02_主题深度笔记/11_生产系统与合规架构.md`
> 运行日期：2026-08-10 ｜ 状态：✅ 运行成功

## 目的

把主题 11 的 risk_gate 扩展为完整模拟器，直观验证核心工程原则：
**"绝不让单个 LLM 幻觉直接 sizing 进组合"**（主报告 §6 / AgentPit 2026-04 行业共识）。

## 运行环境

- Windows + Python 3.14 / numpy（零外部依赖）
- 运行命令：`python main.py`（秒级）

## 模拟设计

1. **LLM 信号生成器**：95% 输出合理信号（目标仓位 1-3%），5% 输出"幻觉信号"
   （确信度 100% + 目标仓位 50% = 5000 万，远超单笔 500 万限额）——模拟 LLM 幻觉；
2. **独立风控层**：逐信号检查 4 类约束（单笔金额/单只头寸/行业暴露/当日换手），
   只看约束不看信号理由；
3. **公平对比**：两条路径用**相同随机种子** → 生成完全相同的信号序列，
   唯一差异是有无风控层。

## 结果摘要（2026-08-10 运行）

| 指标 | 无风控（直连下单） | 有风控（叠加层） |
|---|---|---|
| 幻觉信号生成总数 | 4 | 4（相同序列 ✓） |
| 幻觉信号进入组合 | **4** | **0** |
| 被风控拦截的幻觉 | — | **4/4** |
| 组合最大单只头寸 | **72.6%**（失控） | **10.0%**（约束内） |
| 风控拒绝总次数 | — | 116 |

## 结论

1. **无风控**：4 个幻觉信号（各 5000 万）直接进组合，最大单只头寸 72.6%——
   单点风险敞口完全失控；
2. **有风控**：幻觉信号 4/4 被拦截，最大头寸压在 10% 约束内——风控层不看
   "确信度 100%"的理由，只看约束；
3. **工程含义**：LLM 幻觉无法根除，但独立风控让它无法 sizing 进组合——
   这是 LLM 进生产的必要条件（与金发〔2026〕8 号"人工监督干预 + 可解释性"呼应）。

## 局限

- 模拟信号序列（非真实 LLM 输出）；约束参数为演示值；
- 未模拟熔断/压力测试（可扩展）；教学演示，不构成交易建议。
