# 实验 05：Point-in-Time 数据库为什么重要 —— 幸存者偏差量化演示

> 对应主题：`02_主题深度笔记/05_端到端AI量化管线_Qlib与RD-Agent.md`
> 关联：Microsoft Qlib（GitHub PR #343, 2022-03 引入 PIT 数据库）、RD-Agent(Q)（arXiv 2505.15155）
> 运行日期：2026-08-09 ｜ 状态：✅ 运行成功

## 目的

用真实 A 股数据量化"幸存者偏差"对回测的危害——这是 Qlib point-in-time (PIT) 数据库
存在的根本原因。

## 运行环境

- Windows + Python 3.14 / pandas / yfinance（联网拉数据）
- 运行命令：`python main.py`（首次拉数据约 1-2 分钟，之后走缓存）

## 实验设计

1. 拉取 30 只 A 股大盘股 3 年日线（2023-08 ~ 2026-08，728 交易日）
2. 模拟退市：按"死亡前 6 个月累计收益最低"标记 10 只退市股（真实退市股生前跑输），
   死亡点（第 480 日，2025-07-31）后数据缺失
3. **视角 A（PIT，正确）**：每时点等权持有"当时有数据"的全部股票——退市股死亡前
   的亏损被如实计入
4. **视角 B（幸存者，错误）**：整个回测只持有最终存活的股票——等价于"用今天还
   活着的股票回测过去"

## 结果摘要（2026-08-09 运行）

| 视角 | 年化收益 | 年化 Sharpe | 累计收益 |
|---|---|---|---|
| PIT（每时点可知截面） | 2.82% | 0.17 | +8.35% |
| 幸存者偏差（剔除退市股） | 5.19% | 0.31 | +15.75% |

**幸存者偏差虚高幅度：+6.8% 累计收益**（年化差 2.37pct、Sharpe 差 0.14）。

## 结论

1. 仅"剔除退市股"这一项就足以系统性扭曲回测结论——退市股死亡前的亏损尾部被
   静默删除，回测收益与 Sharpe 双双击穿的虚高。
2. 这正是 Qlib PIT 数据库的工程意义：
   - 因子值带 `update_time` 字段，只有在该时点之后才可用（杜绝未来函数）；
   - 成分股列表也是 PIT 的（回测某天用"那天实际是成分股"的股票）。
3. **面试关联**：本实验与用户实习中"时空坐标系锁定/杜绝未来函数"直接呼应——
   把实习的工程纪律上升为"PIT 数据库设计"的理论自觉。

## 局限

- 模拟退市（真实退市中部分股票是并购退市、收益未必跑输），实际偏差方向一致但幅度因市场而异；
- 等权组合不含成本；真实回测还需交易成本与滑点（见主题 07）。
