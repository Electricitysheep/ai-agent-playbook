# 实验 06：另类数据情绪因子 vs 量价因子的正交性验证

> 对应主题：`02_主题深度笔记/06_另类数据与LLM解析.md`
> 关联论文：Which Voices Move Markets?（arXiv 2604.13260）、Beyond Sentiment（arXiv 2607.28496）、
> Neudata 2026 另类数据市场报告
> 运行日期：2026-08-09 ｜ 状态：✅ 运行成功

## 目的

验证"文本/情绪因子与传统量价因子正交"的方法论管道：自身 IC → 相关性 → 偏相关，
判断文本因子是否提供增量信息（面试核心：LLM 语义因子 vs 传统因子的互补性检验怎么落地）。

## 运行环境

- Windows + Python 3.14 / pandas / yfinance / urllib（联网）
- 运行命令：`python main.py`（首次拉数据+新闻约 2-3 分钟，之后走缓存）

## 数据

- 行情：yfinance 拉 20 只美股（AAPL/MSFT/GOOG/NVDA 等）2 年日线
- 新闻：Google News RSS（公开、无需 key）拉每只股票新闻标题，词典法情绪打分
  （Loughran-McDonald 风格财经情绪词表，可复现、可审计；是 LLM 情绪的简化版）

## 结果摘要（2026-08-09 运行）

**检验 a（自身 IC/ICIR，h=1）**：
- mom20: IC=-0.0147 / ICIR=-0.043；vol20: IC=+0.0293 / ICIR=+0.070
- sentiment: IC=-0.0047 / ICIR=-0.020（词典法情绪自身预测力弱——诚实结果）

**检验 b（因子相关性）**：
- |corr(sentiment, mom20)| = 0.033，|corr(sentiment, vol20)| = 0.147
- **→ 情绪与量价因子低相关，正交性初步成立**

**检验 c（偏相关，控制 mom20+vol20 后）**：
- 情绪对收益偏相关均值 -0.0105 / ICIR -0.044
- 偏相关弱说明词典法情绪自身预测力有限；正交性（低相关）已由检验 b 确认

## 结论

1. **正交性验证的三步管道（自身IC → 相关性 → 偏相关）已跑通**，是文本因子上库前的
   标准纪律，对应主报告"IC/衰减/互补性三道检验"红线。
2. **词典法 vs LLM 的差距**：词典法情绪在本实验 IC 弱（-0.0047），而论文证据显示
   FinBERT 级 LLM 情绪才有显著 alpha（2604.13260：电话会情绪月 alpha 2.03%、t=6.49，
   且完全吞并词典法）——"情绪怎么做"直接影响信号价值，LLM 语义比关键词更有效。
3. **局限（诚实记录）**：新闻情绪是"时点快照"（非时序），20 只股票 × 2 年是小样本；
   正交性结论需更大面板 + LLM 版本情绪 + 衰减测试复核。
