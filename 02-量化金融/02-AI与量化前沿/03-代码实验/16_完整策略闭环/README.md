## 核心价值（为什么 REJECTED 是最好的结果）

1. **诚实拒收 > 假装成功**：6 个弱因子合成的信号 OOS 无 alpha（Sharpe=-0.01），
   DSR 修正多重检验后显著性为 0——管道正确识别并拒绝，而不是"调参调到看起来能赚"。
2. **与实验 12/13/14 逻辑闭环**：弱因子环境下无真实预测力，全链路一致地得出
   "此信号不可用"——这就是回测纪律的体系化体现。
3. **每个环节只用历史信息（无前视）**：IC 权重在 IS 估计、OOS 只应用；
   DSR 用各因子 OOS SR 的方差做多重检验基准（论文标准做法）。
4. **面试金句**："我搭了一条完整策略管道，它跑出来 REJECTED——但我认为这是
   它最好的表现：不是'回测 Sharpe 3'的幻觉，而是诚实地告诉你信号不可用。
   真正的量化纪律是敢拒绝。"

## 关键工程细节（踩坑修复）

- **DSR 公式 bug 修复**：最初 `sr0 = sqrt(2 ln N)·(std/mean)` 在 mean≈0 时产生巨大负基准
  导致虚假 PASS（DSR=1.0）；修正为论文标准：`sr0 = sqrt(2 ln N)·sqrt(Var(试验 SR))`，
  用各因子真实 OOS Sharpe 的方差——修正后正确 REJECTED。
- **教训**：DSR 的门槛是"基准抬高"，基准算错会让整个决策反向——统计实现必须对照
  论文公式逐项验证（López de Prado 2014）。
