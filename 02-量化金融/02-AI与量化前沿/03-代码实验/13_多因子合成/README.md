# 实验 13：多因子合成 —— LightGBM vs IC 加权 vs 等权（walk-forward 内评估）

> 对应主题：`02_主题深度笔记/01_LLM因子挖掘工程化.md`、`05_端到端AI量化管线_Qlib与RD-Agent.md`
> 衔接：RD-Agent 的"Alpha Integration"环节、Chain-of-Alpha 的"集成模型"环节
> 运行日期：2026-08-10 ｜ 状态：✅ 运行成功（诚实结果）

## 目的

用真实 A 股数据，在统一 walk-forward 框架内比较三种因子合成方式：
1. **等权**（各因子 z-score 后平均）——无学习基线
2. **IC 加权**（按因子近期 IC 加权）——线性自适应
3. **LightGBM**（学习因子→收益非线性映射）——ML 集成

## 运行环境

- Windows + Python 3.14 / lightgbm 4.7 / yfinance / pandas / numpy
- 运行命令：`python main.py`

## 设置

- 25 只 A 股 3 年日线，6 个基础量价因子，预测 h=5
- walk-forward：IS 180 天 / OOS 60 天 → 8 个窗口
- 所有合成参数（均值/标准差/IC 权重/模型）**只在 IS 上估计，OOS 只应用**（无泄漏）

## 结果摘要（2026-08-10 运行）

| 合成方式 | 综合 OOS IC | 分层多空日均 | 正 IC 窗口数 |
|---|---|---|---|
| 等权 | -0.0651 | -0.569% | 2/8 |
| **IC 加权** | **-0.0445** | **-0.289%** | 4/8 |
| LightGBM | -0.0162 | -0.506% | 3/8 |

## 核心结论（诚实）

1. **三种合成在弱因子环境下 OOS 全部无效（负 IC）**——因子本身无预测力时，
   合成方式救不了。这是与实验 12 一致的核心教训：**先有强因子，再谈合成**。
2. **相对差异仍有信息**：IC 加权正 IC 窗口最多（4/8）、多空损耗最小（-0.29%）——
   自适应权重在弱信号下比等权少亏；LightGBM 综合 IC 最接近 0（-0.016）
   但多空表现差（学到噪声的典型）。
3. **工程要点**：合成的均值/权重/模型全部 IS 估计、OOS 只应用——泄漏的合成
   （全样本统计）会系统性高估 OOS（主题 07 的预处理泄漏红线）。
4. **面试用法**："我比较过三种因子合成，在弱因子环境下 IC 加权优于等权、
   LightGBM 容易学到噪声——所以合成前先过三道检验，因子质量决定合成上限。"

## 局限

- 25 只小面板 + 6 个简单因子（无行业中性化）——不构成合成方法优劣的普适结论；
- LightGBM 超参未调（演示配置）；未加 DSR/PBO 复核。
