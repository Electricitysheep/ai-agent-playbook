# 实验 01：LLM 因子挖掘的"三道检验"落地管道

> 对应主题：`02_主题深度笔记/01_LLM因子挖掘工程化.md`

> 运行日期：2026-08-09 ｜ 状态：✅ 运行成功

## 目的

把"LLM 因子挖掘"中**检验环节**（方法论红线）做成可运行管道，用真实 A 股日线数据验证：
**IC/ICIR → 衰减测试 → 互补性检查**三道检验 + 前视陷阱演示 + 最终筛选决策。

不调真实 LLM（无 API key），用 9 个公式化候选因子模拟 LLM 输出——检验环节 100% 真实。

## 运行环境

- Windows 11 + Python 3.14.2（pandas 3.0.3 / numpy 2.4.6 / yfinance 1.5.1）
- 数据：yfinance 拉取 20 只 A 股大盘股近 2 年日线（2024-08 ~ 2026-08，485 个交易日），缓存于 `data_cache.parquet`

## 运行命令

```bash
python main.py
```

（需联网；首次运行拉数据约 1-2 分钟，之后走缓存秒级）

## 候选因子池（模拟 LLM 输出）

| 因子 | 语义 | 预期 |
|---|---|---|
| mom20 / rev5 / vol20 / vwap_dev / corr_pv / amt_trend / high_low | 经典量价因子 | 视数据而定 |
| noise_mom | 无逻辑公式拼接（模拟"看起来合理"的 LLM 幻觉因子） | 应无效 |
| lookahead | 前视伪造因子（因子=当日收益） | 检验必抓 |

## 结果摘要（2026-08-09 运行）

**检验 1（IC/RankIC/ICIR，h=1）**：全部 9 个因子未过阈值（IC<0.02 或 ICIR<0.25）→ 最终 0 通过。
这是**真实且重要的教学结果**：20 只股票的小截面样本下，单因子日频 IC 噪声极大、数值很低（|IC| 普遍 0.001-0.04 量级），
实盘因子库需要数百至数千只股票 + 更长历史才有统计功效。**小样本 + 高阈值 = 全淘汰，本身就是正确管道的表现**。

**检验 1b（前视陷阱演示）**：
- lookahead 因子 vs 同日收益（h=0）：**IC = 1.0000**（伪造假象）
- lookahead 因子 vs 次日收益（h=1）：**IC = -0.0355**（正确错位后的真实值）
- 结论：若回测框架把因子当日的收益也算进标签，任何动量类因子都会伪造出 IC≈1 的假象。
  这是新手回测最常犯的错误（用户实习中"杜绝未来函数"的工程化对应）。

**检验 2（衰减测试）**：IC 随持有期 h∈{1,5,10,20} 变化。
- mom20：h=1 时 0.008 → h=10 时 0.048（动量在中周期 10 日最有效——A 股中周期动量特征）
- vwap_dev：h=10/20 时 0.058/0.058（偏离均值回复类信号在更长期限体现）
- 反转 rev5 长周期转负（-0.033@h=20），与动量形成互补结构

**检验 3（互补性）**：相关矩阵显示
- mom20 与 vwap_dev 相关 **0.84**（同为趋势类信号，冗余）
- vol20 与 high_low 相关 **0.83**（同为波动类信号，冗余）
- 与 Chain-of-Alpha 论文 Diversity 指标 `D = 1 - min_corr` 直接对应

## 结论与局限

1. **管道正确性已验证**：三道检验 + 前视演示 + 筛选逻辑全部可运行、结果可解释。
2. **小样本局限**：20 只股票 × 485 天无法得出任何因子有效性结论（也正因为如此全部淘汰是诚实的）。
   真实落地需要：全市场股票池（A 股 5000+）或至少指数成分（CSI 500 的 500 只）、5+ 年历史、分行业中性化。
3. **未做的环节**：真实 LLM 调用（无 key）、换手率/成本建模（Chain-of-Alpha 的 E=TURNOVER^-1 维度）、
   行业/市值中性化、walk-forward 样本外验证（见主题 07 实验）、多因子合成（LightGBM）。
4. 本实验仅为教学演示，不构成投资建议。
