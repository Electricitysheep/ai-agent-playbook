## 快速开始

```bash
# 克隆仓库后进入任意实验目录
cd 02-量化金融/02-AI与量化前沿/03-代码实验/01_LLM因子三道检验/
python main.py

# 依赖缺失时
pip install pandas numpy yfinance baostock
```

**推荐顺序**：01 → 12 → 16（最小闭环：因子检验 → 防过拟合 → 完整策略）

## 方法论亮点

- 每个实验**自包含**：数据缓存本地生成，不依赖外部 API
- 关键环节标注**方法论红线**（如 PIT 对齐、前视陷阱、多重检验）
- 结果可复现：固定种子 + 结果落盘（`result*.pkl/json`，不入 git）
