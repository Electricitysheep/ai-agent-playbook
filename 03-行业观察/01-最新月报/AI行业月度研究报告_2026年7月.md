### 1.2 月之暗面 Kimi K3 旗舰发布：万亿参数MoE与架构创新（7月28日）

2026 年 7 月 28 日，月之暗面（Moonshot AI）正式宣布开源其旗舰大模型 **Kimi K3** 的全量权重（API 已于 7 月 16 日上线），并发布了详尽的技术报告。作为国内首个达到 2.8 万亿总参数量的开源 MoE 模型，Kimi K3 在模型架构、训练稳定性和强化学习方面展现出多项突破性创新。

#### 1. 基础架构与核心参数矩阵

Kimi K3 构建在高达 2.8 万亿（2.8T）的总参数之上，单 Token 激活参数量为 1,040 亿（104B）。模型设计采用了极高稀疏度的 MoE 路由机制，并融合了自研的混合注意力与量化方案。

| 维度 | 参数 / 特性 | 工业级工程意义 |
|---|---|---|
| **参数规模** | 总参数 2.8T / 激活参数 104B | 兼顾极高知识容量与高效推理吞吐 |
| **网络深度与结构** | 93 层，96 Attention 头，Hidden Dim 7168 | 深层拓扑提供极强的高阶逻辑表征能力 |
| **MoE 路由配置** | 896 专家，每 Token 激活 16 专家 + 2 共享专家 | 激活专家比达 1.8%（16/896），远超 K2（8/384） |
| **注意力机制** | 69 层 KDA + 24 层 Gated MLA（3:1 混合排列） | 大幅削减 KV-Cache 内存墙，提升长文本吞吐 |
| **上下文窗口** | **1,048,576 Token（1M）** | 原生支持超长代码库与极长历史对话的无损上下文 |
| **激活函数** | SiTU-GLU | 动态控制激活值范围，平滑高维梯度流动 |
| **量化训练** | MXFP4 权重 / MXFP8 激活（从 SFT 阶段引入 QAT） | 实现极高压缩比下的精度无损落地 |

#### 2. 三大核心架构突破解析

##### (1) KDA（Kimi Delta Attention）—— 线性与选择性注意力 3:1 混合
传统 Transformer 在处理 1M 超长上下文时，KV-Cache 的内存开销与解码延迟呈现 $O(N)$ 线性增长。Kimi K3 提出了 **KDA 混合注意力机制**，将自研的线性注意力层（KDA）与带门控的多头潜变量注意力（Gated MLA）按 **3:1** 的比例交替排列。
- **KDA 层（占 3/4）**：利用固定大小的动态记忆向量（State Vector）进行增量更新与信息覆盖。解码阶段无需保留全量历史 KV-Cache，使 **KV-Cache 占用减少最高 75%**，在 1M Token 超长解码下的**计算吞吐提升最高 6 倍**。
- **Gated MLA 层（占 1/4）**：保留精确的全局注意力选择能力，确保高难度推理与跨文档检索的零精度损失。

##### (2) AttnRes（Attention Residuals）—— 跨深度选择性残差
标准 Transformer 的等权重残差累加（$x_{l+1} = x_l + f(x_l)$）在深层网络（如 93 层）中会导致早期的浅层语义被严重稀释。K3 引入了 **AttnRes 机制**：
- 采用 Block 级别的跨深度注意力选择，每层网络可以根据上下文需求，从更早的层级输出中**选择性检索与加权提取**特征，而非均匀累加。
- 实验数据显示，AttnRes 机制在保持同等模型表达能力的前提下，**为预训练节省了约 20% 的计算算力**。

##### (3) Per-Head Muon 优化器与 QK-Clip 稳定化解法
在将 Muon 优化器应用至 104B 激活参数规模时，团队遇到了严重的 Attention Logit 爆炸问题（Logit 值快速突破 1000 导致 Loss Spike）。K3 基于 K2 的 **MuonClip** 理论进行了升级：
- 引入 **Per-Head QK-Clip**（固定阈值 $\tau = 100$），当特定 Attention 头计算出的 $S_{\max}^h > \tau$ 时，按比例 $\gamma = \tau / S_{\max}^h$ 缩放该头独立的 Query/Key 投影矩阵（$W_{qc}^h, W_{kc}^h$）。
- 这种逐头独立剪切（Per-Head Clipping）避免了全局剪切造成的无差别干预，彻底消除了百亿激活参数 MoE 训练中的梯度不稳定难题。

```
Standard Transformer Layer:
Input -> [ MLA Attention ] -> [ Standard Residual Add ] -> [ SwiGLU MoE ] -> Output

Kimi K3 Layer (3:1 Interleaved):
Layer 1-3: Input -> [ KDA Linear Attn ] -> [ AttnRes Selective ] -> [ SiTU MoE (16/896) ]
Layer 4:   Input -> [ Gated MLA ]      -> [ AttnRes Selective ] -> [ SiTU MoE (16/896) ]
```

#### 3. 强化学习（RL）双轨奖励与防退化机制

Kimi K3 在 Post-Training 阶段全面升级了 RL 框架，采用**双轨奖励系统（Dual-Track Reward Architecture）**：
1. **Verifiable Reward（可验证奖励轨）**：针对数学、代码生成、Terminal 命令执行、逻辑推理及格式约束等 5 类客观任务，引入自动化编译/单元测试/执行器进行绝对真值反馈。
2. **Self-Critique Rubric Reward（自评量表奖励轨）**：针对开放式主观生成与复杂长流程规划，利用超大判别模型基于多维度 Rubric 量表进行 Self-Critique 打分。
3. **防退化控制机制**：结合动态预算控制（Budget Control）、PTX Loss（预训练交叉熵损失正则）与 Temperature Decay（退火衰减），有效避免了 RL 过程中的模式崩溃（Mode Collapse）与语言能力退化。

#### 4. 基准测试表现与真实 Agent 复杂任务表现

在最高推理努力（Reasoning Effort = Max, Temp = 1.0）设定下，Kimi K3 展现出了逼近国际顶级闭源模型的基准表现：
- **GPQA Diamond**：得分 **93.5**（逼近 GPT-5.6 Sol 的 94.1）；
- **Terminal-Bench 2.1**：得分 **88.3**（逼近 GPT-5.6 Sol 的 88.8）；
- **SWE-Marathon**：得分 **42.0**（超越 Claude Opus 4.8 的 40.0）。

在实际工业级 Agent 任务测试中，Kimi K3 展示出了惊人的长程自治工程能力：能够**自主完成复杂 GPU Kernel 优化**（针对 AttnRes/KDA/MLA 进行手写 CUDA/Triton 优化）、**从零构建类 Triton 编译器（MiniTriton）**，并在连续 48 小时不间断演进中独立完成了某微架构芯片的前端逻辑设计。

- **Agent System Harness**：针对企业级多智能体协同系统，提供统一的环境隔离、状态机路由、上下文压缩、异常拦截与审计日志记录，充当智能体系统的“操作系统内核”。

- **上下文精准裁剪**：引入 AST 级上下文路由机制，自动解析代码依赖树，避免将无关代码送入 Prompt，大幅节省 Token 开销并提高回答准确率；
- **模块化插件 Harness**：允许企业自定义安全沙箱与内部 API 鉴权中间件。
