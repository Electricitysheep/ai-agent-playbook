## TL;DR 三句话

1. **本周期三大主题**：Desktop v2 体验重构完成 · Session Snapshot 可回滚（含文件改动）· MCP/插件/SDK 生态成熟化。
2. **最值得立刻用的功能**：`--auto` + snapshot/revert 的"放手流"（试错成本归零）、MCP OAuth 终于稳定可用、Plugin hooks 自动化胶水。
3. **CLI 与 Desktop 不是二选一**：配置与会话完全共享。CLI 干活（serve/API/编排），Desktop 验收（review 面板/diff/多会话监控）。

## 一、近期更新详解（按主题）

### 1. 🖥️ Desktop v2 大改版（本周期最大工程）

v1.18.0（07-14）正式完成迁移，新旧界面有临时切换开关（v1.17.19）。

| 更新 | 版本 | 说明 |
|------|------|------|
| Chrome 式标签页 | v1.17.11/14 | `Mod+1~9` 切换、拖拽重排、中键新标签打开、重开已关闭标签、后台打开 |
| 会话 hover 预览 | v1.17.13 | 标签悬停显示项目/路径/分支/server |
| 重写 prompt 输入框 | v1.18.4 | 命令/上下文/shell/附件/历史交互更可靠 |
| v2 review 面板 | v1.17.14 起持续打磨 | 持久文件浏览、行内文件预览标签、大 diff 性能优化、行评论恢复 |
| 性能 | v1.17.8 / v1.18.0 | Home 冷加载大幅提速；session timeline 秒开、不闪烁、滚动不跳 |

### 2. ⏪ Session Snapshots & Revert（v1.17.11，杀手级）

- 会话任意时刻自动快照，可**回滚到任意一条历史消息 —— 文件改动一起回滚**。
- v1.17.4 已优化：快照复用 git 对象，大仓库不再长时间 re-hash。
- **意义**：可以放心让 agent 大刀阔斧地改，不满意一键回到过去。激进自动化的安全底座。

### 3. 🔌 MCP 全面强化（贯穿整个周期）

| 方面 | 内容 | 版本 |
|------|------|------|
| OAuth 稳定化 | refresh token scope、过期自动重连（含并发）、回调绑 IPv4 loopback、可配回调端口 | v1.17.12 → v1.18.8 |
| Resource 支持 | resource template 列举+读取工具、composer 自动补全 MCP resources、server instructions 注入会话 | v1.17.10/12 |
| **Code Mode Adapter** | 对 MCP 工具跑**受限编排脚本**；`execute` 工具默认隐藏，启用 code mode 才出现 | v1.17.14 |
| 本地 server | `cwd` 支持（workspace 相对目录启动）；MCP server 可拿到当前 workspace 作为 client root | v1.17.4 / v1.17.7 |

> 💡 Code Mode 是"脚本化编排工具链"方向的重要信号，值得持续跟踪。

### 4. 🧩 Plugin / SDK / API v2 成型

- **V2 Plugin API**（v1.17.10）：Effect 与 Promise 两种写法 + namespaced hook API。
- **SDK 大扩**（v1.17.12）：实时事件订阅流、active sessions 访问、分页持久会话历史、权限请求端点、`V2Event` SSE。
- **意义**：外部程序驱动 OpenCode 的接口基本齐了 —— 可以把 agent 能力嵌进任意流水线。

### 5. 🤖 模型与 Provider 跟进

- **新增/适配**：Azure GPT-5.6、Claude Sonnet 5 adaptive thinking、Kimi 在 Anthropic 兼容 provider 上的 adaptive thinking（默认摘要式推理输出）、GLM-5.2 `high`/`max` variants、Meta Muse Spark 专属 system prompt、Grok reasoning effort variants。
- **修复**：Mistral 推理历史跨轮保留 + prompt cache 稳定、xAI Responses 缓存路由 + PDF、Copilot 模型路由。

### 6. 🎛️ 控制与交互细节

## 二、进阶玩法清单

> 以下配置均来自官方文档，可直接抄。配置优先级（合并而非覆盖）：
> `.well-known/opencode`(组织) → `~/.config/opencode`(全局) → `opencode.json`(项目) → `.opencode/` → `OPENCODE_CONFIG_CONTENT`(运行时)

### 玩法 1：Snapshots + `--auto` 的"放手流" 🔥

```bash
opencode --auto    # 所有 ask 自动批准（显式 deny 仍拦截）
```

配合权限白名单让 agent 全自动跑，出问题用 snapshot/revert 回滚到任意消息节点。**试错成本归零。**

### 玩法 2：权限矩阵 + 子代理编排的"防火墙流"

```jsonc
// opencode.json
{
  "subagent_depth": 2,  // 允许 编排器→子代理→孙子代理（默认 1，0=全禁）
  "agent": {
    "orchestrator": {
      "mode": "primary",
      "permission": {
        "task": {
          "*": "deny",               // 默认禁派
          "orchestrator-*": "allow", // 白名单前缀放行
          "code-reviewer": "ask"     // 敏感的要问
        }
      }
    }
  }
}
```

配合 `hidden: true` 把内部子代理从 `@` 补全隐藏，只暴露编排入口。

### 玩法 3：Plugin hooks 做"自动化胶水"

`.opencode/plugins/*.ts`，三个高价值 hook：

```typescript
// ① 防泄密：禁止读 .env
export const EnvProtection = async () => ({
  "tool.execute.before": async (input, output) => {
    if (input.tool === "read" && output.args.filePath.includes(".env")) {
      throw new Error("Do not read .env files")
    }
  },
})

// ② 所有 shell 自动注入密钥（交易 API key 等）
export const InjectEnv = async () => ({
  "shell.env": async (input, output) => {
    output.env.HELIUS_API_KEY = process.env.HELIUS_API_KEY
  },
})

// ③ 自定义 compaction：压缩时保住关键上下文（持仓、策略参数）
export const Compaction = async () => ({
  "experimental.session.compacting": async (input, output) => {
    output.context.push(`## 必须保留\n- 当前持仓与成本\n- 已确认的策略参数`)
  },
})
```

> 量化/链上分析长会话不翻车的关键：`shell.env` 注入密钥 + compaction 保住策略状态。

### 玩法 4：自定义 Tools —— 业务逻辑变 agent 一等公民

`.opencode/tools/*.ts`，**同名覆盖内置工具**：

```typescript
// .opencode/tools/portfolio.ts
import { tool } from "@opencode-ai/plugin"

export default tool({
  description: "查询当前投资组合持仓",
  args: { wallet: tool.schema.string() },
  async execute(args, { directory }) {
    return JSON.stringify(await fetchHoldings(args.wallet))
  },
})
```

比 MCP 更轻 —— 不用起服务，一个文件就是一个工具。

### 玩法 5：OpenCode 当"引擎" —— serve + HTTP API

```bash
opencode serve --port 4096
OPENCODE_SERVER_PASSWORD=secret opencode serve   # 带认证
```

关键端点：`POST /session/:id/prompt_async`（异步发消息）、事件订阅流（收进度）、`/config` GET/PATCH。
**应用场景**：币价异动 → 自动开 session 分析 → 结果推回。CI、Orca 自动化、自写脚本均可驱动。

### 玩法 6：references —— 跨项目上下文

```jsonc
{
  "references": {
    "backtrader-docs": { "repository": "mementum/backtrader", "branch": "master" },
    "strategy-lib":    { "path": "../shared-strategies" }
  }
}
```

对话里 `@backtrader-docs/...` 直接引用外部仓库文件，多仓库研究不用手动喂上下文。

### 玩法 7：模型分层省钱

```jsonc
{
  "model": "anthropic/claude-sonnet-4-5",       // 主力
  "small_model": "anthropic/claude-haiku-4-5",  // 标题/摘要/轻活
  "agent": {
    "plan":  { "model": "anthropic/claude-haiku-4-5" },
    "build": { "model": "anthropic/claude-sonnet-4-5" }
  }
}
```

`ctrl+t` 切 reasoning variant（Anthropic `high`/`max`；OpenAI `none`~`xhigh`）：难活开 max，杂活用 low。

### 玩法 8：实验功能尝鲜

```bash
OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS=1 opencode  # 后台子代理：不阻塞主会话
OPENCODE_EXPERIMENTAL_WORKSPACES=1                      # workspace 支持
```

## 三、CLI vs Desktop：怎么选

> 个人结论（2026-07，已有 Antigravity + Claude Desktop + Codex 的前提下）：**装，但别换。**

### 继续以 CLI/TUI 为主力

1. **工作流是脚本化的**：`opencode serve` + HTTP API + Orca 编排 + 后台子代理，只有 CLI/headless 能承载。
2. **配置完全共享**：opencode.json / skills / agents / MCP 在两端是同一份，零迁移成本，不存在选边站。
3. **桌面端已饱和**：Antigravity（agentic IDE）+ Claude Desktop（日常对话）+ Codex，OpenCode Desktop 与它们重叠度高，再加一个"主力桌面"边际收益低。

### Desktop v2 值得装的场景

| 场景 | 为什么 Desktop 明显更好 |
|------|------------------------|
| **Review + Revert** | 可视化 diff 面板 + 一键回滚到任意消息（含文件改动）。agent 大改后用 Desktop 验收，体验远超翻终端 |
| **多会话驾驶舱** | Chrome 式标签 + hover 预览（项目/分支/server）+ 标签恢复，适合并行盯多个长任务 |
| **随手感性调模型** | per-prompt 模型选择（v1.17.19），composer 里直接切，CLI 要敲命令 |

### 定位建议

```
CLI/TUI  = 干活层（编排、自动化、API、长任务）
Desktop  = 验收层（review diff、snapshot 回滚、多会话监控）
两者共用配置与会话，互补不冲突
```

## 四、速查表

### 常用命令

```bash
opencode --auto                    # 自动批准 ask 权限
opencode run --attach :4096 "..."  # 连到运行中的 server 执行任务
opencode serve --port 4096         # headless 服务模式
opencode session list / export     # 会话管理 / 导出 Markdown
opencode agent create              # 交互式创建 agent
opencode mcp auth <name>           # 触发 MCP OAuth
/compact  /undo  /share            # TUI 内高频命令
```

### TUI 高频键位（leader 默认 `ctrl+x`）

| 键位 | 作用 |
|------|------|
| `Tab` | 切换主 agent（build ↔ plan） |
| `ctrl+t` | 切模型 reasoning variant |
| `<leader>n` / `<leader>l` | 新会话 / 会话列表 |
| `<leader>c` / `<leader>u` | 压缩上下文 / 撤销上一条 |
| `escape` | 中断当前响应 |
| `@agent名` | 直接调用子代理 |
| `!命令` | shell 输出注入上下文 |

### 权限键一览

`read` / `edit` / `bash` / `glob` / `grep` / `task`（子代理）/ `skill` / `lsp` / `webfetch` / `websearch` / `external_directory` / `doom_loop`（同调用重复 3 次）

### 关键实验开关

```bash
OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS=1   # 后台子代理
OPENCODE_EXPERIMENTAL_WORKSPACES=1             # workspace
OPENCODE_ENABLE_EXA=1                          # websearch 工具
OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1          # 关 Claude 兼容层
```
