## TL;DR（5行费曼门槛）

1. **K3 是 2.8T 总参、104B 激活参数的 MoE 模型**，1M 上下文，16/896 激活专家比，MXFP4+QAT 量化，93层，KDA+MLA 混合注意力。
2. **架构创新有三条可学习路径**：KDA 线性注意力（3:1 interleave 比例）、AttnRes 跨深度残差连接（省20%计算）、Per-Head Muon 优化器（Muon 的 per-head 变体，暂无公开论文）。
3. **K2 的 MuonClip 优化器是 K3 的工程基础**：per-head QK-Clip（τ=100）解决了 Muon 在百亿激活参数下的 logit 爆炸问题，附录有理论分析；数据 rephrasing 策略（知识类 + 数学类）提升 token utility 显著。
4. **RL 训练核心是双轨奖励**：Verifiable Reward（5类可验证任务）+ Self-Critique Rubric Reward（模型自评），配合 Budget Control + PTX Loss + Temperature Decay 防退化。
5. **Agent 能力最强案例**：K3 自主完成 GPU kernel 优化（AttnRes/KDA/MLA）、从零构建类 Triton 编译器（MiniTriton）、48小时完成芯片设计、2小时完成 PhD 级天体物理计算。

## 二、架构创新（从业者能学到什么）

### 2.1 KDA（Kimi Delta Attention）—— 3:1 混合注意力

KDA 是一种**混合线性注意力机制**，按 3:1 比例与标准 MLA 层交替排列：

- **KDA 层**（3层）：线性注意力，维持固定大小记忆向量，按需覆盖旧信息，KV-cache 减少最高 **75%**，1M token 解码速度提升最高 **6×**
- **Gated MLA 层**（1层）：保留全局信息流动的精确注意力
- KDA 融合 MLA 的低秩投影技巧（latent representation），推理时 Key 不全量展开

> **复用价值**：KDA 论文编号 arXiv 2510.26692，可独立查阅。K3 使用的混合比例（3:1）可能需实验调参，但线性注意力思路可直接迁移。

### 2.2 AttnRes（Attention Residuals）—— 跨深度选择性残差

标准残差等权重累加导致深层信息稀释。AttnRes 用**跨深度的注意力机制**替代：
- 每层从更早层输出中**选择性检索**，而非均匀累加
- Block 级别 AttnRes（将层分组，组内跨层 attention）
- 效果：比标准残差**节省约 20% 训练计算量**，同时保持等效性能

> **复用价值**：arXiv 2603.15031，公开论文，可直接复现。Block 级别是已验证变体。

### 2.3 Stable LatentMoE + 四个配套机制

稀疏度从 K2 的 8/384 提升到 16/896（1.8% 激活比），配套四个机制：

| 机制 | 作用 | 可复用性 |
|---|---|---|
| **Quantile Balancing** | 从 router-score 分位数推导专家分配，无需敏感平衡超参 | ⚠️ 细节未公开，需逆向 |
| **Per-Head Muon** | 逐注意力头独立优化 Muon，学习率自适应 | ⚠️ 无公开论文 |
| **SiTU-GLU** | 改进激活函数，控制激活值范围 | ❌ 无公开公式 |
| **Gated MLA** | 改进 MLA 的选择性 | 继承自 K2 MLA |

## 三、预训练：可复用的关键技术

### 3.1 Muon + QK-Clip（来自 K2 的最值钱发现）

**核心问题**：Muon 在扩展到百亿激活参数时出现 **attention logit 爆炸**（值快速超 1000），导致 loss spike。

**QK-Clip 机制**（Algorithm 1，K2 论文 Section 2.1）：

`
For each attention head h:
  S_max^h = max_{X∈B} max_{i,j} Q_i^h · K_j^h / sqrt(d)
  if S_max^h > τ:
    γ = τ / S_max^h
    W_qc^h *= sqrt(γ)    # head-specific qc
    W_kc^h *= sqrt(γ)    # head-specific kc
    W_qr^h *= γ          # head-specific rotary
    # kR（shared）不动，避免跨头干扰
`

- τ=100 固定，全程无需调整
- 只有少数 head 会爆炸，**per-head clipping 比 global clipping 干预更少、效果更好**
- MLA 同样适用（只需对 unshared 组件 clip）

> **复用价值**：极高。Muon 已在百亿激活参数规模验证有效，per-head QK-Clip（τ=100）是经过验证的稳定化方案。K2 附录提供了 Muon 比 AdamW 更易爆炸的理论分析（结构差异 + SVD 形式 + attention 放大效应），值得一读。

### 3.2 数据 Rephrasing 策略（Knowledge + Math）

**核心观点**：高质量 token 稀缺，token efficiency 成为关键缩放系数。

**Knowledge Rephrasing**（K2 Section 2.2）：
- **Chunk-wise 自回归改写**：长文档分段重写，拼回全文，避免隐式输出长度限制
- **多风格多视角 prompt**：多样化但不损失事实性
- **语义一致性验证**（fidelity verification）
- 每个语料库最多 rephrase **2 次**

**Ablation 实验**（SimpleQA）：

| Rephrasings | Epochs | Accuracy |
|---|---|---|
| 0 | 10 | 23.76 |
| 1 | 10 | 27.39 |
| 10 | 1 | **28.94** |

结论：rephrasing 策略优于简单重复暴露，10 rephrasings × 1 epoch 效果最好。

**Mathematics Rephrasing**：领域专业化改写技术（Section 2.2.2，细节未公开）。

> **复用价值**：直接可用。Chunk-wise + fidelity verification 是可复用的工程pattern，不依赖特定模型。

## 四、后训练与 RL（来自 K2，K3 可能继承）

> K3 的 SFT/RL 细节未完全公开，以下为 K2 的详细 Pipeline（arXiv 2507.20534 Section 3），K3 很可难继承并扩展。

### 4.1 大规模 Agentic 数据合成（六步 Pipeline）

1. **Domain Evolution and Tool Generation**：工具域不断扩展，用 LLM 生成新工具描述和实现
2. **Agent Diversification**：多样化 Agent 个体（不同角色/风格/能力画像）
3. **Rubric-Based Task Generation**：基于评分规则生成任务，确保覆盖度和难度可控
4. **Multi-turn Trajectory Generation**：生成长程交互轨迹
5. **Quality Evaluation and Filtering**：质量评估和过滤
6. **Hybrid with Real Execution**：合成环境 + 真实执行环境混合

> 复用价值：高。Pipeline 结构清晰，步骤 1-4 可直接迁移到自己的 agent 数据合成流程。

### 4.2 双轨奖励机制（RLVR + Self-Critique）

**① Verifiable Rewards（RLVR）**：5 类可验证奖励
- Math / STEM / Logical Tasks
- Complex Instruction Following
- Faithfulness
- Coding & Software Engineering
- Safety

**② Self-Critique Rubric Reward**：超越可验证任务的开放式奖励
- 模型自己批判自己的输出
- 用 rubric 评分作为奖励信号
- 闭式 critic refinement + 对齐

> 原文：The model learns not only from externally defined tasks but also from evaluating its own outputs, extending alignment from static into open-ended domains.

### 4.3 RL 算法三件套

| 机制 | 作用 |
|---|---|
| **Budget Control** | 限制每回合 token 预算，防止 RL rollout 过长 |
| **PTX Loss** | 新增 loss 项，控制 token 混合比例，避免无效思考 token 膨胀 |
| **Temperature Decay** | 训练过程逐步降温度，平衡探索与利用 |

> 复用价值：高。三件套都是工程上可直接借鉴的防退化手段。

## 五、Agent 能力：从 K3 案例看 LLM 的能力边界

### 5.1 最强案例（来自 tech blog）

**GPU kernel 优化**：K3 在晚期开发阶段**自主完成团队大部分 kernel 优化**，涵盖 AttnRes、KDA、MLA kernel（512 head-dim）在 NVIDIA Hopper 和替代 GPGPU 上的性能调优。

**MiniTriton 编译器**：K3 从零构建了类 Triton 编译器：
- Tile-level IR layer over MLIR
- 优化 passes + PTX code generation pipeline
- 端到端 nanoGPT 训练稳定收敛
- Roofline benchmarks 与 Triton 持平或更好

**48小时自主芯片设计**：Nangate 45nm 开源 EDA 工具，4mm²，100MHz，8700 tokens/s，1.46M 标准单元，INT4 MAC array。

**科研加速**：2小时完成 PhD 级天体物理计算（通常1-2周）：审阅20+论文 → 实现数值pipeline → 评估300+方程 → 发现已发表公式不一致 → 3000+行Python → 交互式HTML dashboard。

### 5.2 已知的行为特性（来自 README/Limitations）

1. **Thinking History 敏感性**：K3 训练模式为"preserved thinking history"，agent harness 必须将完整历史（含 easoning_content 和 	ool_calls）原样回传，否则质量急剧下降。
2. **过度主动性**：K3 强化学习了长程挑战任务，遇到模糊指令会主动替用户做决策。

## 八、从业者提炼：可复用清单

### ✅ 可直接借鉴

1. **Muon + per-head QK-Clip（τ=100）**：百亿激活参数规模验证有效，MLA 也适用（只需 unshared 组件 clip）
2. **Knowledge Rephrasing**：chunk-wise 自回归改写 + fidelity verification，有 ablation 数据支撑
3. **Hybrid Agentic Data**：合成 + 真实执行环境混合，避免分布偏移
4. **Verifiable Reward + Self-Critique Rubric 双轨**：有明确答案用 RLVR，开放任务用 model-as-critic
5. **PTX Loss + Budget Control**：防 RL 无效 token 膨胀的实用组合
6. **Selective Recomputation + FP8 存储**：激活内存优化的经典组合
7. **AttnRes（Block-level）**：公开论文 arXiv 2603.15031，可直接复现

### ⚠️ 需进一步研究

- **KDA**：arXiv 2510.26692 已发，但 K3 用 3:1 混合版，最优 ratio 需实验
- **Quantile Balancing**：专家分配从分位数推导，细节未公开
- **Per-Head Muon**：无公开论文
- **SiTU-GLU**：新激活函数，无公开公式

### ❌ 无法复现

- 完整数据 pipeline（数据来源、配比、过滤规则）
- 完整 RL 超参（budget 数值、temperature decay 曲线、PTX 系数）
- 预训练 token 数量（K3 未公开）
- 训练集群架构（MoonEP 自研通信层）
- 许可（Kimi K3 License 包含商业附加条件）
