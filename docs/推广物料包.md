### 首楼框架

> 过去 8 个月边实习边积累，把 AI Agent 工程 + 量化金融的学习笔记整理成了开源知识库。
>
> 整理过程中几个体会：
> 1. **Agent 源码拆解比看文档有用得多**——Claude Code Agent Teams 的邮箱+flock 机制、Devin 的权限委托链路，都是直接读源码得出的（每篇标注证据分级：官方文档/社区逆向/本机实测）
> 2. **A2A 协议还在早期**——调研了 14 家主流 agent，发现"agent 间直接互发消息"只有 4 家支持，大多数是 hub-and-spoke 编排
> 3. **AI × 量化是几乎没人做的交叉点**——从 LLM 因子挖掘到生产风控做了 16 个可运行实验
>
> 知识库地址：https://github.com/Electricitysheep/ai-agent-playbook
> 全部内容原创，欢迎 star / 提 issue / PR 共建。
